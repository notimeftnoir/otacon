# Support

Need help with Otacon? Here's where to go.

## Documentation first

- [`README.md`](README.md) — install, usage, CLI flags, output formats, FAQ, troubleshooting
- [`docs/DESIGN.md`](docs/DESIGN.md) — architecture, scoring rationale, performance characteristics
- [`CHANGELOG.md`](CHANGELOG.md) — what changed in each release
- [`SECURITY.md`](SECURITY.md) — hardening posture and how to report a vulnerability

## Bug reports

If something is broken, [open an issue](https://github.com/notimeftnoir/otacon/issues/new?template=bug_report.yml) with:

- Otacon version (`otacon --version`)
- Python version, OS, architecture
- The full command and (if safe to share) the target
- Expected vs. actual behavior, including any error output

The bug-report template prompts you through these.

## Feature requests

Have an idea? [Open a feature request](https://github.com/notimeftnoir/otacon/issues/new?template=feature_request.yml). The clearer the use case ("I'm trying to do X and Otacon currently does Y"), the better the chance it lands.

## Security vulnerabilities

**Do not open a public issue for security problems.** Email **gabriel.bieszczad@gmail.com** — see [`SECURITY.md`](SECURITY.md) for the full disclosure process and SLA.

## Questions and discussions

For general "how do I…" or "is this the right tool for…" questions, GitHub Discussions (when enabled) is the right place. In its absence, open a regular issue and prefix the title with `[question]`.

## Commercial support

There is none. Otacon is a community-maintained MIT-licensed project. If your organization depends on it and you'd like to fund a feature or a maintenance bump, reach out to the maintainer email above.
